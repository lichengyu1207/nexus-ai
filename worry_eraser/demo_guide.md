# 烦恼橡皮擦 - 演示指南

## 1. 项目概述

“烦恼橡皮擦”是一个基于房都督平台核心能力的情感陪伴应用，旨在帮助用户倾诉烦恼，获得智能体的共情回应，并生成烦恼分析报告。

### 核心功能：
- 用户倾诉烦恼
- 智能体（周瑜/陆逊）共情回应
- 记忆留存（相似烦恼识别）
- 生成烦恼分析报告
- 演示模式（离线可用）

## 2. 启动流程

### 2.1 安装依赖

```bash
# 在 worry_eraser 目录下执行
pip install -r requirements.txt
```

### 2.2 启动后端服务

**方法一：使用 uvicorn 直接启动**
```bash
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

**方法二：使用 start.bat 脚本（Windows）**
```bash
# 双击运行 start.bat 或在命令行执行
start.bat
```

### 2.3 访问前端

打开浏览器，访问：
```
http://localhost:8000
```

## 3. 演示步骤

### 3.1 基本演示流程

1. **选择智能体**
   - 点击顶部的智能体切换按钮，选择“周瑜”或“陆逊”
   - 观察欢迎消息的变化

2. **倾诉烦恼**
   - 在底部输入框中输入您的烦恼，例如："工作压力大，感觉很疲惫"
   - 点击“发送”按钮或按回车键
   - 观察智能体的回复

3. **生成报告**
   - 点击右侧的“生成报告”按钮
   - 等待报告生成完成
   - 查看烦恼分析报告，包括情绪趋势和建议

4. **测试记忆功能**
   - 再次输入相似的烦恼，例如："最近工作压力还是很大"
   - 观察智能体是否会引用之前的对话

### 3.2 演示模式

如果后端服务无法启动，或网络中断，可以使用演示模式：

1. 在浏览器地址栏中添加 `?demo` 参数：
   ```
   http://localhost:8000?demo
   ```

2. 此时页面会显示“演示模式”标识，前端将使用内置的模拟数据，无需后端服务

3. 按照上述基本演示流程进行操作

## 4. 故障排除

### 4.1 常见问题

1. **端口占用**
   - 错误信息：`Address already in use`
   - 解决方法：检查是否有其他服务占用 8000 端口，或修改端口号

2. **依赖缺失**
   - 错误信息：`ModuleNotFoundError`
   - 解决方法：重新安装依赖 `pip install -r requirements.txt`

3. **数据库初始化失败**
   - 错误信息：`sqlite3.OperationalError`
   - 解决方法：检查 `data.db` 文件权限，或删除后重新启动服务

4. **前端页面无法访问**
   - 错误信息：`404 Not Found`
   - 解决方法：确保后端服务正在运行，且前端文件存在于 `static/index.html`

### 4.2 应急方案

如果演示时遇到严重问题，可使用以下应急方案：

1. **使用演示模式**：通过添加 `?demo` 参数进入演示模式
2. **展示技术架构**：准备幻灯片介绍系统架构和核心功能
3. **分享代码结构**：展示项目文件结构和核心模块

## 5. 赛后反哺计划

### 5.1 情感提示词集成

将 `prompts/consolation.py` 中的情感疏导提示词整理成 JSON 格式，集成到房都督主平台的人格化引擎中，作为可选的情感陪伴风格。

### 5.2 报告模板库

将 `report.py` 中的报告生成逻辑抽象为模板函数，建议房都督主平台增加“报告模板库”，支持用户选择不同报告风格。

### 5.3 记忆检索优化

基于“烦恼橡皮擦”的记忆检索经验，改进房都督主平台的海马体记忆系统，使其在情感陪伴场景下更智能。

## 6. 技术栈

- **后端**：FastAPI、SQLite
- **前端**：HTML、CSS、JavaScript
- **核心模块**：人格引擎、记忆系统、报告生成
- **部署**：Uvicorn 服务器

## 7. 项目结构

```
worry_eraser/
├── main.py                # 主入口
├── personality.py         # 人格引擎
├── memory.py              # 记忆系统
├── report.py              # 报告生成
├── prompts/
│   └── consolation.py     # 情感提示词
├── static/
│   └── index.html         # 前端单页
├── requirements.txt       # 依赖配置
├── start.bat              # Windows 启动脚本
├── start.sh               # Linux 启动脚本
└── data.db                # SQLite 数据库
```
