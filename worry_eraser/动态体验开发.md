# 烦恼橡皮擦“三部曲”动态体验开发指南（1万字AI提示词集）

**作者**：交互叙事设计师 / 全栈架构师  
**目标**：基于你已经开发完成的“烦恼橡皮擦”功能，将其包装成一个类似房都督平台宣传栏的三部曲动态体验，让用户通过点击、悬停等交互，亲眼见证从倾诉烦恼到智能体陪伴、记忆调用、最终生成关怀报告的完整过程。本指南将复用现有后端能力，只需前端增强，即可在1-2天内完成一个可展示的动态叙事组件。  
**阅读对象**：前端开发工程师、动效设计师、AI编程助手  

---

## 一、设计理念：从“功能”到“过程叙事”

你已经有了一个可以工作的烦恼橡皮擦，用户输入烦恼 → 智能体回复 → 记忆存储 → 可选报告。现在要做的，是把这些环节拆解为**可视化的过程**，让用户看到智能体如何“理解”烦恼、“回忆”相似经历、“组织”安慰语言、“生成”关怀报告。这种过程叙事能够极大提升用户的情感投入和对平台的信任感。

借鉴房都督平台宣传栏的经验，我们将设计**烦恼橡皮擦三部曲**：

- **第一幕：倾诉回响**  
  用户输入烦恼后，文字化作光束飞向智能体图标，智能体开始“倾听”，显示正在解析情绪。
- **第二幕：记忆涟漪**  
  系统检索海马体记忆，找到相似烦恼，用粒子动画表现“回忆被唤醒”，智能体在回复中提及过往。
- **第三幕：慰藉成章**  
  生成一份“关怀报告”，包含情绪分析、暖心建议、成长记录，报告内容逐字输出，并配以舒缓的背景动画。

三部曲可以独立播放，也可以串联演示。前端只需增加动画层，后端无需改动（但可增加一些辅助接口如报告生成进度）。

## 二、技术架构与复用策略

### 2.1 复用已有后端
- **`/chat` 接口**：接收用户消息，返回智能体回复和 `memory_id`。
- **`/report` 接口**：根据 `memory_id` 生成关怀报告。
- **记忆系统**：通过 `/memories` 接口获取用户历史烦恼。

### 2.2 前端新增
- **动画控制层**：用 Canvas 或 SVG 绘制光束、粒子、涟漪。
- **场景状态机**：管理三部曲的播放、暂停、重播。
- **音效**：简单背景音乐和音效（可选项）。

### 2.3 技术栈
- React + TypeScript
- Framer Motion（UI过渡）
- Canvas API 或 Three.js（轻量粒子）
- 现有聊天组件复用

## 三、三部曲详细设计与提示词

### 3.1 第一幕：倾诉回响

**场景描述**：用户输入烦恼后，文字化作金色光束飞向智能体图标，智能体图标开始闪烁，表示正在“倾听”。同时，智能体头像下方显示“正在解析你的情绪...”的动态文本。

**交互触发**：用户点击“倾诉”按钮后，自动播放动画，然后调用后端 `/chat` 接口获取回复。

**提示词1：倾诉动画组件**

```markdown
请实现 `ConfessionAnimation.tsx` 组件，用于第一幕。要求：

1. 接收用户输入的文本字符串。
2. 在输入框下方创建一个 Canvas 层，将文本内容逐字拆解为粒子，每个粒子从输入框位置飞出，沿贝塞尔曲线飞向左侧的智能体图标（周瑜或陆逊头像）。
3. 粒子颜色为金色，大小随距离递减，飞行时间 0.8 秒。
4. 所有粒子飞完后，智能体图标周围出现旋转光环，并开始播放“思考”动画（Lottie 或 CSS 脉冲）。
5. 在图标下方显示提示文字“正在解析你的情绪...”，文字逐字出现（打字机效果）。
6. 动画完成后，自动调用后端 `/chat` 接口，并将返回的智能体回复显示在聊天区。
7. 组件应可重置，以便重播。
```

**提示词2：情绪解析状态机**

```markdown
在聊天界面的状态管理中，增加 `emotionParsing` 状态。当用户发送消息后，状态变为 `emotionParsing`，触发上述动画。动画结束后状态变为 `fetchingReply`，等待 API 返回。回复到达后，状态变为 `idle`。请实现对应的状态流转和 UI 反馈。
```

### 3.2 第二幕：记忆涟漪

**场景描述**：当智能体回复中包含“我记得你上次...”等记忆调用时，在聊天背景中触发涟漪动画，表现记忆被唤醒。同时，在界面上方可显示一个“记忆卡片”，展示被调用的历史烦恼摘要。

**触发条件**：后端返回的回复中若包含特定的记忆引用标记（可在提示词中要求模型输出 `{{memory:xxx}}` 标记），前端解析后触发动画。

**提示词3：记忆涟漪动画组件**

```markdown
请实现 `MemoryRipple.tsx` 组件，用于第二幕。要求：

1. 监听智能体回复，检测是否包含 `{{memory:xxx}}` 格式的标记（其中 xxx 是记忆 ID）。
2. 若有，解析出记忆 ID，调用 `/memories/{id}` 接口获取该记忆内容。
3. 在聊天区域中央或背景中，从记忆被引用的位置（智能体气泡）向外扩散一圈圈半透明的蓝色涟漪，涟漪逐渐扩大并消失，共扩散 3 圈，每圈间隔 0.3 秒。
4. 同时，在聊天区上方滑入一个“记忆卡片”，显示记忆摘要（如“你曾说过：工作压力大”），卡片停留 3 秒后淡出。
5. 如果连续出现多个记忆引用，涟漪和卡片依次出现（队列）。
6. 动画使用 Canvas 或 SVG，避免影响其他布局。
```

**提示词4：记忆卡片组件**

```markdown
实现 `MemoryCard.tsx` 组件，用于展示被调用的记忆。要求：
- 卡片为毛玻璃效果，圆角，内边距 12px，阴影。
- 包含图标（回忆）和文字内容。
- 从右侧滑入，停留 3 秒，向左滑出。
- 可叠加显示多个（但建议排队）。
```

### 3.3 第三幕：慰藉成章

**场景描述**：用户可主动点击“生成关怀报告”按钮，系统逐字显示报告内容，包括情绪分析、暖心建议、成长记录。报告内容可以基于历史记忆和本次对话生成。

**技术实现**：复用现有的 `/report` 接口，但前端需要增加逐字渲染和动画效果。

**提示词5：报告生成动画组件**

```markdown
请实现 `CareReportAnimation.tsx` 组件，用于第三幕。要求：

1. 接收报告 JSON 数据（包含标题、摘要、分析段落、建议列表、成长记录等）。
2. 渲染区域分为左右两栏：左栏为报告主体，右栏为情绪趋势图（简单折线图）。
3. 主体内容逐字出现（打字机效果），每个段落出现前有淡入动画。
4. 图表数据从报告中的 `emotion_trend` 字段读取，使用 Recharts 绘制，数据点依次出现（动画）。
5. 报告完全显示后，右下角出现“下载报告”按钮，点击可导出 PDF 或图片。
6. 支持暂停、重播功能。
```

**提示词6：报告生成进度模拟**

```markdown
如果后端报告生成耗时较长，前端可模拟进度条。实现 `ReportProgress.tsx` 组件，显示“正在生成报告...”的环形进度条，进度由 0% 逐渐增加到 100%，然后显示报告内容。进度增长可通过 setTimeout 模拟，实际报告返回后立即显示。
```

### 3.4 三部曲串联控制器

**提示词7：三部曲主控制器**

```markdown
请实现 `TrilogyController.tsx` 组件，用于管理烦恼橡皮擦的三部曲流程。要求：

1. 包含三个步骤指示器（1.倾诉回响、2.记忆涟漪、3.慰藉成章），当前步骤高亮。
2. 提供“播放三部曲”按钮，自动依次播放三个场景（需用户先输入烦恼，或使用预设示例）。
3. 每个场景播放时，显示对应的动画组件，并自动触发必要的 API 调用。
4. 支持单独重播某个场景。
5. 场景之间切换有淡入淡出过渡。
6. 所有动画依赖真实 API 数据，不依赖模拟。
```

## 四、集成到现有烦恼橡皮擦

### 4.1 修改聊天界面

在现有聊天组件中，嵌入三部曲控制器。聊天界面仍然保持原有功能，但增加“体验三部曲”的入口（如一个悬浮按钮），点击后展开全屏或模态框播放动态演示。

**提示词8：三部曲入口与模态框**

```markdown
在聊天界面右上角添加“✨ 体验烦恼橡皮擦三部曲”按钮。点击后打开一个模态框，全屏或半屏，内部嵌入 `TrilogyController` 组件。模态框背景半透明，有关闭按钮。用户可在模态框内完成三部曲体验，体验结果可保存到正常聊天记录中。
```

### 4.2 复用现有 API

无需修改后端，但需确保：

- 聊天 API 返回的回复中，如果需要记忆引用，应包含特殊标记（可在提示词中要求模型输出 `{{memory:xxx}}`）。你可以在人格引擎的提示词中增加指令：“当你回忆起用户的过往烦恼时，请在回复中用 `{{memory:记忆ID}}` 标记，以便前端展示动画。”
- 报告 API 应返回结构化的 JSON，包含 `emotion_trend` 字段（数组）。

### 4.3 适配移动端

三部曲动画在移动端需简化，避免性能问题。

**提示词9：移动端降级方案**

```markdown
在屏幕宽度 < 768px 时，三部曲动画改为静态示意图，取消粒子效果，记忆卡片改为简单 Toast 提示。所有动画时长缩短至 0.3 秒以内。用户点击“播放三部曲”时，直接显示文字说明和最终报告，跳过中间动画。
```

## 五、效果展示与测试

### 5.1 演示场景示例

- **示例 1**：用户输入“最近工作压力大”，系统第一幕光束飞向智能体，第二幕回忆上次相似烦恼（如“你曾说过加班太多”），第三幕生成报告。
- **示例 2**：用户无历史记忆，则第二幕跳过记忆涟漪，直接显示提示“暂无相关回忆”。

### 5.2 测试清单

- 光束动画流畅，粒子不卡顿。
- 记忆卡片出现时机准确，内容与回复一致。
- 报告生成动画逐字输出，图表绘制平滑。
- 三部曲重播功能正常，无内存泄漏。
- 移动端简化版可正常使用。
