# Task Engine

This directory contains the task engine system, responsible for managing and executing analysis tasks and workflows.

## Structure

- `task_manager.py`: Manages task lifecycle and state
- `workflow_engine.py`: Handles workflow definition and execution
- `step_executor.py`: Executes individual task steps

## Key Responsibilities

- Create and manage analysis tasks
- Define and execute task workflows
- Monitor task progress and status
- Handle task dependencies and retries
- Ensure tasks are executed efficiently and reliably
