# AI Agents

This directory contains the AI agent system for the application, responsible for performing intelligent tasks like property analysis.

## Structure

- `agent_factory.py`: Factory class for creating different types of agents
- `base_agent.py`: Base class for all agents, defining common interface
- `property_analyzer.py`: Agent specialized in property analysis

## Key Responsibilities

- Create and manage AI agents for different tasks
- Handle agent communication and coordination
- Process data using AI models
- Generate insights and recommendations
